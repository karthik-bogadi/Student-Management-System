# Student Management System

A simple Student Management System built using Spring Boot, JSP, and MySQL.

## Features

- Add Student
- Update Student
- Delete Student
- View Students

## Technologies Used

- Java
- Spring Boot
- JSP
- MySQL
- HTML
- CSS
